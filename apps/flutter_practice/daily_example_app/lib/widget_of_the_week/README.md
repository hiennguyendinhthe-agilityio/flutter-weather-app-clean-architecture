# 🎓 Flutter Widget of the Week - Systematic Learning Curriculum

## 🎯 Objective
Learn all important Flutter widgets through the "Widget of the Week" series in a systematic, practical, and most effective way.

## 📚 Learning Methodology
Each lesson includes 4 main sections:
1. **📖 Theory**: Explanation of widget, properties, and usage
2. **🎮 Interactive Demo**: Direct experimentation with properties
3. **💡 Real Examples**: Common use cases in real apps
4. **📝 Exercises**: Practice to reinforce knowledge

## 🗓️ 32-Week Learning Roadmap

### 🏗️ Week 1-4: Foundation Widgets
- **Week 01**: Container - The most basic widget for layout
- **Week 02**: Row & Column - Arrange widgets horizontally/vertically
- **Week 03**: Stack - Layer widgets on top of each other
- **Week 04**: Positioned - Precise positioning within Stack

### 📐 Week 5-8: Layout Widgets
- **Week 05**: Expanded & Flexible - Flexible space distribution
- **Week 06**: Wrap - Auto line break when space runs out
- **Week 07**: ListView - Scrollable list
- **Week 08**: GridView - Grid data display

### 👆 Week 9-12: Interactive Widgets
- **Week 09**: GestureDetector - Detect user gestures
- **Week 10**: InkWell - Ripple effect on touch
- **Week 11**: Hero - Screen transition animation
- **Week 12**: Transform - Geometric widget transformation

### ⌨️ Week 13-16: Input Widgets
- **Week 13**: TextField - Text input
- **Week 14**: Form - Form management and validation
- **Week 15**: Checkbox & Radio - Single/multiple selection
- **Week 16**: Slider - Sliding value selector

### 🖼️ Week 17-20: Display Widgets
- **Week 17**: Image - Display images
- **Week 18**: Icon - Material Design icons
- **Week 19**: Card - Cards with shadow and elevation
- **Week 20**: Chip - Small interactive labels

### 🧭 Week 21-24: Navigation Widgets
- **Week 21**: TabBar - Tab switching bar
- **Week 22**: Drawer - Side sliding menu
- **Week 23**: BottomNavigationBar - Bottom navigation bar
- **Week 24**: PageView - Swipe page transitions

### 🎬 Week 25-28: Animation Widgets
- **Week 25**: AnimatedContainer - Container with animation
- **Week 26**: AnimatedOpacity - Fade in/out effects
- **Week 27**: AnimatedBuilder - Custom animation creation
- **Week 28**: Tween - Animation value interpolation

### 🚀 Week 29-32: Advanced Widgets
- **Week 29**: CustomPaint - Custom drawing with Canvas
- **Week 30**: StreamBuilder - Build UI from Stream
- **Week 31**: FutureBuilder - Build UI from Future
- **Week 32**: LayoutBuilder - Responsive layout by size

## 📊 Progress Tracking System
- ✅ Completed: Widget learned and exercises done
- 🔄 In Progress: Current widget
- ⏳ Pending: Upcoming widgets

## 🎯 End-of-Course Goals
After 32 weeks, you will:
- Master all basic and advanced widgets
- Confidently build complex UIs
- Understand Flutter layout system deeply
- Create animations and custom widgets
- Be ready for real-world projects
